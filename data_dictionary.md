# Initial Data Dictionary

## CityState

Role: Lookup/reference table for unique city and state combinations.

| Attribute | Data type | Meaning | Key status | Data source | Cleaning, transformation, or assumptions |
| --- | --- | --- | --- | --- | --- |
| city_state_id | INT | Surrogate identifier for a city/state pair. | Primary key | Generated by `raw_data_processor.py` | Assigned sequentially after collecting distinct city/state pairs. |
| city | VARCHAR(100) | City name. | Candidate key with `state` | `uszips.csv.city`; apartment raw `cityname` | Trimmed; blank values are skipped unless recovered from previous listing context. |
| state | CHAR(2) | Two-letter state abbreviation. | Candidate key with `city` | `uszips.csv.state_id`; apartment raw `state` | Trimmed and converted to uppercase. |

## ZipCodeDemographics

Role: Reference table for ZIP-level demographic and coordinate data.

| Attribute | Data type | Meaning | Key status | Data source | Cleaning, transformation, or assumptions |
| --- | --- | --- | --- | --- | --- |
| zip | CHAR(5) | ZIP code. | Primary key | `uszips.csv.zip`; sometimes extracted from listing body | Trimmed and zero-padded to 5 digits; placeholder rows may be added for listing ZIPs missing from `uszips.csv`. |
| population | INT | Population for the ZIP code. | None | `uszips.csv.population` | Missing or invalid values are filled with `0`. |
| latitude | DECIMAL(9,6) | ZIP latitude. | None | `uszips.csv.lat` | Invalid or missing values are filled with `0`. |
| longitude | DECIMAL(9,6) | ZIP longitude. | None | `uszips.csv.lng` | Invalid or missing values are filled with `0`. |

## Address

Role: Core entity table for listing addresses.

| Attribute | Data type | Meaning | Key status | Data source | Cleaning, transformation, or assumptions |
| --- | --- | --- | --- | --- | --- |
| address_id | INT | Surrogate identifier for an address. | Primary key | Generated by `raw_data_processor.py` | Assigned sequentially to unique address rows. |
| street_number | VARCHAR(50) | Street number or placeholder number. | Candidate key with `street_name`, `zip`, `city_state_id` | Apartment raw `address`; apartment raw `id` for placeholders | Parsed from address string; set to listing id or sequence value when address is missing. |
| street_name | VARCHAR(255) | Street name or placeholder value. | Candidate key with `street_number`, `zip`, `city_state_id` | Apartment raw `address` | Parsed from address string; set to `Unknown` when address is missing. |
| zip | CHAR(5) | ZIP code for the address. | Foreign key to `ZipCodeDemographics(zip)`; candidate key with address fields | Extracted from apartment raw `body`; fallback from `uszips.csv` | Uses extracted ZIP if valid; otherwise uses first matching ZIP for city/state. |
| city_state_id | INT | City/state associated with the address. | Foreign key to `CityState(city_state_id)`; candidate key with address fields | Derived from listing city/state | Missing listing city/state may reuse previous valid city/state. |

## ApartmentListing

Role: Core entity/fact table for apartment rental listings.

| Attribute | Data type | Meaning | Key status | Data source | Cleaning, transformation, or assumptions |
| --- | --- | --- | --- | --- | --- |
| listing_id | INT | Surrogate identifier for a processed listing. | Primary key | Generated by `raw_data_processor.py` | Assigned sequentially; one physical apartment data line becomes one listing. |
| address_id | INT | Address where the listing is located. | Foreign key to `Address(address_id)` | Generated by matching listing address to `Address` | Added to implement the `Locate At` relationship from the ER diagram. |
| title | VARCHAR(255) | Listing title. | None | Apartment raw `title` | Trimmed; missing titles become `Apartment Listing <id>`. |
| description | TEXT | Listing description/body. | None | Apartment raw `body` | Trimmed; newline, carriage return, and null characters removed. |
| bedrooms | INT | Number of bedrooms. | None | Apartment raw `bedrooms` | Parsed as integer; missing or invalid values are filled with `0`. |
| price | DECIMAL(10,2) | Listing price. | None | Apartment raw `price` | Parsed as decimal; missing or invalid values are filled with `0`. |
| bathrooms | DECIMAL(4,1) | Number of bathrooms. | None | Apartment raw `bathrooms` | Parsed as decimal; missing or invalid values are filled with `0`. |
| square_feet | INT | Listing size in square feet. | None | Apartment raw `square_feet` | Parsed as integer; missing or invalid values are filled with `0`. |
| listing_time | DATETIME | Time the listing was posted. | None | Apartment raw `time` | Unix timestamp converted to datetime; shifted so newest listing date is `2026-07-28`. |
| latitude | DECIMAL(9,6) | Listing latitude. | None | Apartment raw `latitude` | Parsed as decimal; missing or invalid values are filled with `0`. |
| longitude | DECIMAL(9,6) | Listing longitude. | None | Apartment raw `longitude` | Parsed as decimal; missing or invalid values are filled with `0`. |

## Amenity

Role: Lookup/reference table for amenity names.

| Attribute | Data type | Meaning | Key status | Data source | Cleaning, transformation, or assumptions |
| --- | --- | --- | --- | --- | --- |
| amenity_id | INT | Surrogate identifier for an amenity. | Primary key | Generated by `raw_data_processor.py` | Assigned sequentially after sorting unique amenity names. |
| amenity_name | VARCHAR(100) | Amenity label. | Candidate key | Apartment raw `amenities` | Split from comma-separated raw amenity list and trimmed. |

## ListingAmenity

Role: Bridge table implementing the many-to-many relationship between `ApartmentListing` and `Amenity`.

| Attribute | Data type | Meaning | Key status | Data source | Cleaning, transformation, or assumptions |
| --- | --- | --- | --- | --- | --- |
| listing_id | INT | Listing that provides the amenity. | Composite primary key; foreign key to `ApartmentListing(listing_id)` | Generated from apartment listing rows | One row is created for each listing/amenity pair. |
| amenity_id | INT | Amenity provided by the listing. | Composite primary key; foreign key to `Amenity(amenity_id)` | Derived from apartment raw `amenities` | References normalized amenity values. |

## AppUser

Role: Application support table for user accounts.

| Attribute | Data type | Meaning | Key status | Data source | Cleaning, transformation, or assumptions |
| --- | --- | --- | --- | --- | --- |
| user_name | VARCHAR(100) | Unique username for an application user. | Primary key | Application/user input | Assumed unique and required. |
| email | VARCHAR(255) | User email address. | Candidate key | Application/user input | Assumed unique; should be validated by the application. |

## Review

Role: Transaction/fact table for user reviews of apartment listings.

| Attribute | Data type | Meaning | Key status | Data source | Cleaning, transformation, or assumptions |
| --- | --- | --- | --- | --- | --- |
| review_id | INT | Surrogate identifier for a review. | Primary key | Generated by database or application | Assigned when a user creates a review. |
| user_name | VARCHAR(100) | User who wrote the review. | Foreign key to `AppUser(user_name)` | Application/user input | Must reference an existing application user. |
| listing_id | INT | Listing being reviewed. | Foreign key to `ApartmentListing(listing_id)` | Application/user input | Must reference an existing listing. |
| rating | INT | Numeric rating for the listing. | None | Application/user input | Assumed to use a fixed rating scale such as 1 through 5. |
| review_text | TEXT | Written review content. | None | Application/user input | May be optional depending on application rules. |
| review_time | DATETIME | Time the review was submitted. | None | Generated by database or application | Stored when the review is created. |

## SavedListing

Role: Bridge table implementing the many-to-many relationship between `AppUser` and `ApartmentListing`.

| Attribute | Data type | Meaning | Key status | Data source | Cleaning, transformation, or assumptions |
| --- | --- | --- | --- | --- | --- |
| user_name | VARCHAR(100) | User who saved the listing. | Composite primary key; foreign key to `AppUser(user_name)` | Application/user action | Must reference an existing application user. |
| listing_id | INT | Listing saved by the user. | Composite primary key; foreign key to `ApartmentListing(listing_id)` | Application/user action | Must reference an existing listing; composite key prevents duplicate saves. |
